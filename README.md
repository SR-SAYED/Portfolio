# MD Sayedur Rahman — Portfolio

Visit: https://sr-sayed.github.io/portfolio/

## Updating the portfolio

This is a responsive, one-page, data-driven portfolio. Its editable content is kept in one place:

`data/portfolio.json`

The visual design is in `css/styles.css`. `js/portfolio.js` renders the data, manages the mobile navigation, and adds section animations.

Keep the profile image, browser icon, and other images in `static/images/`. Keep CV and other PDFs in `static/files/`.
